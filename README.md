# Richmond Tienyine Portfolio

This repository contains the static portfolio website for Richmond Tienyine.

## Local preview

Open `index.html` in a browser, or serve the repository with any static file
server.

## GitHub Pages

The site is ready to publish with GitHub Pages from the repository's `main`
branch and root directory. The public entry point is `index.html`.

The contact form is currently presentational only; GitHub Pages does not run
the included PHP runtime.
